# AI image prompts — "हर राज्य का सुपरहिट खाना"

**Kaise use karein:** Har prompt ko ChatGPT / Gemini / Bing Image Creator / Ideogram mein paste karein.
Jo image bane, use **neeche likhe file name** se save karein aur `video_studio/assets/stickers/` folder mein
daal dein. Phir video dobara render karein. Jis dish ki image nahi hogi, uski jagah emoji dikhega.

**Har prompt ke end mein yeh style line zaroor jodein (taaki saari images ek jaisi lagein):**

> `, appetizing food photography, single serving centered, top 3/4 angle, soft warm studio light, isolated on a plain pure white background, no text, no hands, no people, square 1:1`

Monetization ke liye: image aapke account se generate honi chahiye. YouTube description mein likhein:
"Food images are AI-generated illustrations."
